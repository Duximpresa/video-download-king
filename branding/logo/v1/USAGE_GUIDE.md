# Logo 使用规范

## 标准颜色

- 品牌红：以透明 PNG 母版中的原始红色为准，近似 `#FA0100`。
- 黑色描边：`#000000`。
- 箭头与高光：`#FFFFFF`。

不得擅自改为渐变、添加阴影、发光、纹理或额外颜色。

## 留白

Logo 四周至少保留相当于箭头杆宽度一半的空白。不得让文字、边框或其他图形进入该区域。

## 最小尺寸

- 数字界面建议不小于 `32×32 px`。
- `16×16 px` 仅用于 favicon 或系统小图标。
- 印刷建议宽度不小于 `10 mm`。

尺寸较小时允许高光细节自然弱化，但不得重新绘制或改变箭头比例。

## 背景

- 首选白色、浅灰色或透明背景。
- 深色背景可直接使用标准彩色版本。
- 单色印刷时使用 `mono-black` 或 `mono-white` 版本。
- 避免放在高饱和红色、复杂照片或低对比背景上。

## 禁止事项

- 不得拉伸、压扁、旋转或裁切。
- 不得改变红、黑、白的关系。
- 不得移除粗黑描边或白色高光。
- 不得把箭头替换为播放三角形、文字或其他符号。
- 不得在 Logo 内加入产品名称、平台名称或装饰图案。
- 不得模仿或添加 YouTube 的文字标识。

## 文件选择

- Windows EXE、任务栏和快捷方式：使用 `windows/*.ico`。
- 网站 favicon：使用 `web/favicon.ico` 或 `web/favicon-32.png`。
- Windows 窗口、关于页和普通界面：使用 `png/*-512.png`。
- 海报或高分辨率画面：使用 `master/*-logo-v1.png`。

## 母版说明

第一代 Logo 的创作源是位图，因此 `master` 中的透明 PNG 是视觉母版。目前不提供伪装成原生矢量的自动描摹 SVG；若未来需要印刷级 SVG，应在不改变外观的前提下人工描摹，并作为新资产审校。
