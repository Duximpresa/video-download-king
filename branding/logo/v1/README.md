# Video Download King Logo V1

这是 Video Download King 的第一代正式 Logo 归档。

## 设计理念

Logo 将“视频”与“下载”压缩成一个直观、容易记忆的符号：

- 鲜红色圆角方形表达视频媒介与活力。
- 白色向下箭头直接表达下载功能。
- 粗黑色不规则描边强化力量感，并形成独立于常见扁平软件图标的手绘个性。
- 略微歪斜的轮廓和高光保留轻松、亲切的卡通质感。
- 整体仅使用红、黑、白三种主色，确保小尺寸仍有清晰识别度。

该设计借鉴手绘视频图标的视觉语言，但不使用 YouTube 的精确轮廓、比例或播放三角形。

## 目录说明

- `source/`：用户最终选择的原始图片，保留棋盘格背景，不应直接用于产品。
- `master/`：去除棋盘格后的透明 PNG 母版。
- `png/`：常用尺寸 PNG，以及黑白单色版本。
- `windows/`：Windows 多尺寸 ICO。
- `web/`：favicon、Apple Touch Icon 和网页应用图标。
- `preview/`：浅色与深色背景预览。
- `USAGE_GUIDE.md`：详细使用规范。

## 推荐文件

- 桌面程序：`windows/video-download-king-v1.ico`
- 网站和文档：`png/video-download-king-logo-v1-512.png`
- 大尺寸宣传：`master/video-download-king-logo-v1.png`
- 浏览器标签：`web/favicon.ico`

## 版本规则

本目录是不可变的 `v1` 归档。后续若修改轮廓、颜色、箭头或高光，应新建 `v2`，不要覆盖第一代文件。
